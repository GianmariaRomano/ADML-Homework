# ⚙ Algorithmic Methods of Data Mining - Homework

---

## 📚 About this Repository

This repoitory contains my solutions to the Hackerrank exercises proposed by Professors Anagnostopolous and Siciliano for the *Algorithmic Methods of Data Mining* course given as part of the Master's Degree in *Data Science* during the first semester of Academic Year 2026/2027.

All solutions are found in the `scripts.py` file, while the completion certificates can be found in the `printouts/submissions_romano.pdf` file.
